# Hierarquia radical + progressive disclosure (painel do Delta)

O chatter olha o Delta de relance, entre uma mensagem e outra. Cada tela responde a UMA pergunta:
"o que eu mando agora?". Tudo o mais é secundário e espera ser pedido.

## 1. Uma ação dominante por tela
- Na tela da conversa a ação é **Copiar** (o roteiro). É o único botão cheio, na cor de ação.
- Todo o resto é secundário: botão fantasma (sem fundo) ou link. Nunca dois botões cheios lado a lado.
- Na doca (modo mini) a ação continua sendo Copiar, sempre no mesmo lugar (canto inferior direito).
- Sem conversa aberta, não há botão dominante: a tela é a lista "abra nesta ordem".

## 2. Ordem fixa de leitura (de cima para baixo)
1. Bloqueio (PARE / NÃO ENVIE) — o único elemento que pode gritar.
2. Quem é o fã + relógio (estado: verde / amarelo / vermelho).
3. Cartão da jogada: fase → instrução → texto pronto → [Copiar].
4. Abas (Delta / Ficha / Fila / Sumidos / Mais).
5. Linhas dobradas: avisos extras, preço, leitura do fã, meta do dia, recursos, diagnóstico.

## 3. Progressive disclosure
- Nível 1 (sempre visível): o que muda a próxima mensagem. Fã, relógio, fase, texto, Copiar, preço curto (chip).
- Nível 2 (dobrado): Preço, Meta do dia, Leitura e Recursos são **cartões em grade 2×2** (rótulo pequeno + número grande);
  avisos extras, Fila e Diagnóstico são faixas de uma linha. Nada de "lista de configurações" com linhas finas.
  Abre com um clique; o painel lembra o que ficou aberto.
- Nível 3 (dentro da dobra): explicação, origem dos números, nota técnica.
- Texto de diagnóstico ("Leitura da tela: 6 de 6…") nunca no nível 1.

## 4. Estados visuais > texto
- Cor diz o estado (relógio, fase, urgência); a frase só confirma.
- Um ponto colorido + 3 palavras vale mais que uma frase de 20 palavras.
- Número grande, rótulo pequeno e apagado.

- [ ] Dá para dizer em 1 s qual é o botão principal?

- [ ] Algum texto passa de 2 linhas no nível 1? Encurte ou dobre.
